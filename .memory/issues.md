# Issues — 論点（決めないといけないこと）

> **判断が必要な論点だけ**を置く。**やることが明確な作業は書かない**（それは [todo.md](todo.md)）。
> 論点は**決めれば消える**。作業は**やれば消える**。別物なので混ぜない。
>
> 決着したら「決着した論点」へ移す。**このファイルの中で完結する**（`todo.md` へは移さない）。
> 決着の結果として作業が生まれたら、その作業は `todo.md` に書く。

## 優先度の意味

| | 意味 |
|---|---|
| **高** | 放置すると先の作業が手戻りになる。着手前に決めるべき |
| **中** | いずれ決める必要がある。今は動いているので急がない |
| **低** | 決めたほうがよいが、後回しでよい |
