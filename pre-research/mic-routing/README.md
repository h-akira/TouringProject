# mic-routing — インカムのマイクで録れるようにする

**走行中の録音がノイズまみれだった件を、「録音の設定」ではなく
「そもそもどのマイクから録っているか」を疑って測った調査。**

## ⚠️ 結論

✅ **本アプリはインカムのマイクを使えておらず、Pixel 本体マイクで録っていた。**

**原因は `expo-audio` の `setInput()`** — `setCommunicationDevice()` は
⚠️ **出力(sink)しか受け付けない**のに**入力を渡しており、黙って失敗していた。**

✅ **自前のネイティブモジュールで【出力】を渡すようにして、インカムから録れた**
（-13.5 dB・確立 270ms）。

⚠️ **ただしインカムのボタンで起動すると、その張り方（仮想通話）は成り立たなかった**（§9・§10）:
**起動直後は張れず、録音中のボタンは「電話を切る」になって2回目の押下がアプリに届かない。**
✅ **`BluetoothHeadset.startVoiceRecognition()`（音声認識として張る）では成立した**
（起動直後でも 217〜274ms・2回目の押下は SCO の切断として届く）。

> ⚠️ **判断は [adr/010](../../adr/010_intercom_mic_routing.md)。** ここには**実測だけ**を置く。
